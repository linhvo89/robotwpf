Continuous trajectory motion type control
commands:
Starting with HR version 6.3.3, the trajectory functionality has been optimized and
integrated. Some basic concepts are as follows:
The coordinate type of the original point data of a trajectory: there are two types: joint
coordinates (0) and spatial coordinates (1). When a certain trajectory is created, the
coordinate type of its original point data must be determined. Once a trajectory is
created, this attribute cannot be changed.
MovePathJ and MovePathL: A trajectory can be run in either MovePathJ or
MovePathL mode. The premise is that the corresponding target point can be
calculated.
Calculation of target point position of a trajectory: after the original point position
data is collected, the system will automatically start the calculation of target point
position, because there are two kinds of movement methods, so there are two groups
of target point position calculation, and the results of the two groups of calculation are
saved in the database respectively.
Import and export of trajectory: In the front-end interface, you can export the
trajectory to a file or import the trajectory file into the system. 6.3.3 version only
supports the import and export of the trajectory with the joint coordinates as the
original point position.
The status of trajectory: there are 8 kinds of status values: not teaching (0), teaching
(1), teaching finished (4), calculating (2), calculation error (5), calculation completed
(3), imported (9), post-import processing (10), among which, teaching finished,
calculating, imported, post-import processing are temporary statuses, the system will
automatically process them and switch them to the other statuses; imported and
